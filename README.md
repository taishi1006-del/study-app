# study-app

学習の進捗と今日のタスクをまとめて管理する、小さな学習ダッシュボードです。

## 概要

- 今日やることを一覧で確認
- 完了状況をワンタップで切り替え
- 集中時間の目安を表示

## 開発

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```
